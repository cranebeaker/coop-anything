# Tool catalogue for co-op work

Audience: an AI coding agent and its owner, mainly on Windows 10/11, with notes for Linux and Steam Deck where they matter.

How to read this page:

- "Seen in docs" means the install line or fact came from the project's own README or docs page when this page was researched. "Unverified" means it came from a third-party listing, from memory, or could not be confirmed. Re-check before relying on it.
- "Agent-drivable" means there is an MCP server or a scriptable CLI an agent can call without a human clicking in a GUI.
- Licenses are as shown on the project page at research time. Check the LICENSE file before redistributing anything.
- Third-party MCP servers run with your user permissions and often have write access to a debugger or to process memory. Read the source, pin a version, and run them against test copies of games only.

## Legal and safety note

Do not use these tools to bypass anti-cheat on online games, to cheat in other people's sessions, or to redistribute game assets or code you do not have rights to. Many tools below have a stated "your own software" scope (REA and RenderDoc say so explicitly). Test co-op mods in private sessions with friends.

Linux and Steam Deck notes:

- Nucleus and Sandboxie-Plus are Windows only. On Linux, use separate Wine prefixes or Steam Proton prefixes per instance.
- REFramework needs `WINEDLLOVERRIDES="dinput8.dll=n,b" %command%` in Steam launch options. MelonLoader lists Linux support via Wine, Proton or native. BepInEx supports Unity Mono on Linux.
- UE4SS is Windows only per its README, but Windows UE games run under Proton, with the proxy DLL override applied the same way.
- Goldberg lists Linux support (`libsteam_api.so`).

## Suggested starting order for an agent

1. Triage the game: Detect It Easy or the install folder layout tells you the engine. Use `engine-families.md`.
2. Pick the loader from section 2 and verify a hello-world mod loads.
3. Static analysis: Ghidra headless or REA for native, ILSpy or dnSpyEx for Mono, Il2CppDumper or Cpp2IL for IL2CPP, UE4SS dumpers for Unreal.
4. Dynamic analysis only if static is not enough: Cheat Engine or x64dbg on an offline copy, Frida for quick function probes.
5. Test with two instances using Nucleus plus a LAN-only emulator, on your own copies.
6. Keep every installed tool and every MCP server pinned and recorded in the game's notes, so the next agent can reproduce the setup.

## Gaps and items marked unverified

- Direct fetches were not run for SKSE, F4SE, OBSE, Detect It Easy, PE-bear, API Monitor, Rizin, Binary Ninja official docs, Hex-Rays official MCP, gh CLI install, and decomp-toolkit. Their rows rely on memory or search summaries and say so.
